# MemoryPlus

MemoryPlus est une application web d'entraînement cognitif pensée pour aider les personnes à garder leur mémoire, leur attention et leur concentration actives de manière simple, douce et motivante.

“Stimulez votre mémoire, renforcez votre confiance”

## Objectif

MemoryPlus propose des exercices courts et progressifs pour :
- améliorer la mémoire
- renforcer la concentration
- stimuler l'attention
- encourager la régularité
- soutenir les seniors et les familles dans une routine cognitive simple

## Public cible

- personnes âgées
- aidants / familles
- utilisateurs souhaitant garder leur cerveau actif
- centres d'accueil et maisons de retraite

## Fonctionnalités

- 8 exercices cognitifs
- parcours simple et accessible
- sélection du profil utilisateur
- choix du niveau de difficulté
- progression et historique
- paramètres d'accessibilité
- design pensé pour les seniors
- parcours sans pression
